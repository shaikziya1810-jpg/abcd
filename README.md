FrameFinder

About the Project

FrameFinder is a responsive image search web application that helps users find images based on their interests. Users can search for images by entering keywords or selecting a category.

Features

- Search images using keywords.
- Browse Nature, Animals, and Travel categories.
- Display images in a responsive grid layout.
- Show image captions.
- Display loading, empty-result, and error messages.
- Responsive design for desktop and mobile devices.

Technologies Used

- HTML5
- CSS3
- JavaScript
- Wikimedia Commons API

Project Structure

How to Run

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Open "index.html" using Live Server.
4. Enter a search keyword and click Search.
5. Select a category to search for related images.

API

This project uses the Wikimedia Commons API to retrieve image search results. An internet connection is required.

Learning Outcomes

- Understanding HTML page structure.
- Styling responsive layouts using CSS Grid and Flexbox.
- Handling form submissions and button events using JavaScript.
- Fetching API data using "async/await" and "fetch()".
- Displaying dynamic content and handling errors.
